# Portal de Aplicaciones

Versión simple del portal original.

## Estructura

- `index.html`: estructura HTML.
- `styles.css`: estilos que estaban dentro de `<style>`.
- `app.js`: JavaScript original, incluyendo `DATA` con todos los datos de las aplicaciones.

## Importante

Los datos permanecen exactamente dentro de `app.js`, como en el HTML original.
No se utiliza Excel, SQLite, API ni servidor.

## Ejecución

Puede abrirse directamente haciendo doble clic en `index.html`.
